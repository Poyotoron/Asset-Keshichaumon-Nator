# ルートの設定

**ルート**とは「使っている起点」のことです。このツールは、**登録したルートから参照を辿って到達できたものを「使用中」**とみなし、**どこからも辿り着けなかったものを未使用候補**とします。

つまり、ルートの登録漏れは**そのまま誤判定になります。** ここがこのツールで最も重要な設定です。

!!! danger "登録し忘れたアバターの持ち物は、全部「未使用」になります"
    まだ使うアバターは、**必ず全部**登録してください。多めに登録して困ることはありません（候補が減るだけです）。少なく登録すると、使用中の衣装やテクスチャが候補に並びます。

## 3 つの登録方法

**ルート (Roots)** タブで設定します。

### 1. フォルダを登録する

アバターの `.prefab` やシーン（`.unity`）を含むフォルダを登録します。

- ドロップ領域に**ドラッグ＆ドロップ**する
- 「フォルダを選択して追加」から選ぶ

登録したフォルダの中は**再帰的に**走査され、見つかった Prefab / シーンがすべて起点になります。アバターごとにフォルダを分けている人は、この方法がいちばん確実です。

### 2. アバターを自動検出する

「アバターを自動検出」を押すと、`VRCAvatarDescriptor` を持つ Prefab をプロジェクト全体から探します。

- 検出されたものは既定で**すべて起点として扱われます。**
- チェックを外すと、そのアバターだけ起点から除外できます（もう使わない古いアバターを候補に出したいときに使います）。

!!! note "検出されないとき"
    VRChat SDK が入っていない場合や、アバターの Prefab に `VRCAvatarDescriptor` が付いていない場合は検出されません。その場合はフォルダ登録か個別ファイル指定を使ってください。

### 3. 個別ファイルを追加する

単一の Prefab やシーンだけを起点にしたいときに使います。「個別ファイルをルートに追加（任意）」から指定します。Prefab とシーン以外は指定できません。

## 暗黙ルート — 自動的に起点になっているもの

登録していなくても、**参照が無いだけでは消せないもの**があります。これらは自動的に起点として扱われます。**暗黙ルート**と呼びます。

| 自動的に起点になるもの | 理由 |
|---|---|
| `Resources/` 配下 | コードから名前で読み込まれる。参照グラフに現れない |
| `Editor Default Resources/` 配下 | 同上 |
| `StreamingAssets/` 配下 | 同上 |
| Build Settings に登録されたシーン | ビルド対象のため |
| `Assets/` 直下に置かれた `.asset` | 各種ツールの設定ファイルであることが多いため |

「暗黙ルート」の項目を開き、**「暗黙ルートを調べる」** を押すと一覧を確認できます。

### 暗黙ルートを起点から外す

一覧のチェックを外すと、そのファイルを起点から除外できます。**これが必要になる典型的な場面があります。**

衣装変換ツールなどが `Assets/` 直下に設定アセットを作り、その中に「最後に変換した衣装」への参照を持ち続けることがあります。すると——

!!! example "よくある詰まり方"
    ツールの入力欄に残っている値が、そのままスキャンの起点になります。その衣装はもう使っていないのに、**いつまでも「使用中」と判定され、候補に出てきません。**

心当たりがあれば、その設定アセットのチェックを外してください。

!!! warning "外すときは自分で判断してください"
    本当に必要な設定アセットを起点から外すと、**そこからしか参照されていないアセットが候補に出てきます。** 何が起点でなくなるのかを確認してから外してください。

なお、**起点から外したファイル自身は保護されます。** 外した瞬間にそのファイルが消える対象に変わる、ということはありません。

### 「暗黙ルートだけで使用中」の一覧

スキャン結果には **「暗黙ルートだけで使用中」** という一覧があります。ここに並ぶのは、**アバターからは辿れず、暗黙ルート（多くはツールの設定アセット）だけが生かしているもの**です。

- どの暗黙ルートが生かしているのかが表示されます。
- **「起点から外す」**を押すと、その場でその暗黙ルートを起点から除外できます。

「もう使っていないはずなのに候補に出ない」ものは、たいていここに載っています。

## ルートが 1 つも無いとき

起点がゼロの状態ではスキャンできません。すべてのアセットが候補になってしまい、危険だからです。この場合はスキャンが止まり、ルートを設定するよう促されます。
