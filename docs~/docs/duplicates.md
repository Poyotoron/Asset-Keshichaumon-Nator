# 重複アセットの検出

**重複検出 (Duplicates)** タブでは、`Assets/` 配下から**内容が完全に一致するファイル**を探します。

複数の配布物が同じシェーダーやテクスチャを同梱している場合など、**使用中なのに二重・三重に置かれている**ものを見つけるための機能です。未使用アセットの退避では減らせない容量が、ここで見つかることがあります。

## 使い方

**「重複を検出（非破壊）」** を押します。ファイルの内容を SHA-256 で照合するため、プロジェクトが大きいと少し時間がかかります。

結果は「同一内容のファイル群」ごとにまとめて表示されます。

| 表示 | 意味 |
|---|---|
| 同一内容 N ファイル / 各 サイズ | 何個が同じ内容か、1 個あたりのサイズ |
| 余剰 | 1 個だけ残したとして、削れる容量 |
| 使用 | 各ファイルが「使用中」か「未参照」か |

## このタブは何も動かしません

!!! info "検出（レポート）だけの機能です"
    重複が見つかっても、**自動では何も移動・削除しません。** 統合するかどうかは自分で判断してください。

これは慎重さのための仕様です。同一内容のファイルでも、**参照している側はそれぞれ別の GUID を見ています。** 片方を消せば、それを参照していたマテリアルやプレハブは壊れます。

## どう判断するか

| 状況 | 対処の考え方 |
|---|---|
| 全部「未参照」 | どのアバターからも使われていない。[スキャン](scan.md)側で候補に出ていれば、そちらから退避できます |
| 1 つが「使用中」、残りが「未参照」 | 未参照のものは整理できる可能性が高い。ただし配布物のまとまりを壊さないか確認を |
| 複数が「使用中」 | **触らないのが無難です。** それぞれ別のアバターや配布物が参照しています |

!!! warning "配布物のフォルダから一部だけ抜かない"
    「同じテクスチャが 2 つあるから片方消そう」と配布物のフォルダから 1 ファイルだけ抜くと、**その配布物を再インポートしたときに戻ってきたり、更新時に不整合が出たり**します。重複が配布物の同梱物である場合は、そのまま残しておくほうが安全です。

## 手を出すなら

参照ごと統合したい場合は、参照している側（マテリアルやプレハブ）を先に片方へ差し替えてから、不要になったほうを退避してください。**このツールは参照の差し替えは行いません。**
