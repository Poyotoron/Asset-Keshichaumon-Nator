# キャッシュ掃除

アセットを退避しても、`Library/` 配下のビルドキャッシュは縮みません。ここは数 GB〜数十 GB になることがあり、**削除すれば容量を大きく取り戻せます。**

ただし、この操作は他の機能とは性質がまったく違います。

!!! danger "失うのはデータではなく「時間」です"
    削除後、**次回 Unity 起動時に全アセットの再インポートが発生します。** プロジェクトの規模により **数分〜数十分（それ以上になることもあります）** かかります。

    「一瞬で終わる」「とりあえず押しておけばいい」操作ではありません。**`Assets/` が大きい人ほど、代償が大きくなります。**

| | 未使用アセットの退避 | キャッシュ掃除 |
|---|---|---|
| 失うもの | 何も失わない（元に戻せる） | 時間（再インポート） |
| 元に戻せるか | 戻せる | キャッシュは戻らない（作り直される） |
| 危険なのは | 判定の誤り | **時間を過小評価すること** |

!!! warning "この機能は Windows 専用です"
    他の OS では利用できません。

## 何が消えるか

| 対象 | 備考 |
|---|---|
| `Library/` | 本体。再インポートで作り直されます |
| `Temp/` | 一時ファイル |
| `obj/` | ビルド中間物 |
| `.vs/` | Visual Studio のキャッシュ |
| `*.csproj` / `*.sln` | 再生成されます |
| `Logs/` | **任意（既定 OFF）。** 不具合調査に使う可能性があるため |

!!! success "作ったものには一切触れません"
    `Assets/` `Packages/` `ProjectSettings/` は削除対象に含まれません。**アバターも衣装も設定も消えません。**

## 使い方

Unity の実行中は `Library/` を直接消せません。そのため「予約して、Unity 終了時に外部ヘルパーが消す」という方式になっています。

### 1. 規模を確認する

**「サイズを計測 / 更新」** を押します。現在の `Library/` サイズと、`Assets/` のアセット数・合計サイズが表示されます。

**この数字が、そのまま再インポートの重さです。** `Assets/` が大きいほど時間がかかります。

### 2. 予約する

**「次回 Unity 終了時にキャッシュを掃除する（予約）…」** を押します。

確認は二段階です。二段階目には **「再インポートに時間がかかることを理解しました」** というチェックがあり、これを入れないと進めません。

!!! tip "実行するタイミング"
    **作業終了時・離席前・就寝前など、しばらく Unity を使わないとき**に予約してください。「これから作業する」というタイミングで実行すると、再インポートの待ち時間をそのまま食らいます。

予約はいつでも **「予約をキャンセルする」** で取り消せます。

### 3. 普通に Unity を終了する

通常どおり終了すると、外部ヘルパーが Unity の終了を待ってから削除を実行します。**手作業は不要です。**

終了時にはもう一度、予約されている旨の警告が出ます。ここで中止することもできます。

### 4. 次回起動時

再インポートが走ります。**完了するまで Unity は使えません。** 完了までの時間は記録され、次回以降は実測値にもとづく目安が表示されます。

## その他の実行方法

| 方法 | 使いどころ |
|---|---|
| **今すぐ Unity を終了して掃除する…** | すぐ実行したいとき。確認後、Unity が終了します |
| **clean-cache.bat を生成** | うまく動かない環境向け。**Unity を完全に終了してから**手動で実行します |

## よくある質問

**Q. どのくらい時間がかかりますか？**
断定できません。CPU・ストレージ・アセット構成で大きく変わります。SSD でも数分、規模が大きい場合や HDD の場合は数十分以上かかることがあります。一度実行すると、次からは実測値が表示されます。

**Q. 途中で止めたらどうなりますか？**
再インポートを中断すると、次回起動時に続きから再開されます。プロジェクトが壊れるわけではありませんが、**中断しても時間は節約できません。**

**Q. 毎回やるべき？**
いいえ。容量が逼迫したときだけで十分です。日常的にやる操作ではありません。
