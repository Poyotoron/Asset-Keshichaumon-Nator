# 困ったときは

## まず: 退避したものを元に戻す

**スキャン結果 (Scan Result)** タブの下部にある **「退避済みフォルダ」** に、プロジェクト直下の `_UnusedAssets_…` が一覧表示されています。戻したいものの **「復元」** を押してください。

- `.meta` ごと戻すので、**参照も復活します。**
- Unity を再起動したあとでも戻せます。
- 退避フォルダを別の場所へ移動してしまった場合は、「退避フォルダを選んで復元」から手で選べます。

!!! success "スキャンし直す必要はありません"
    退避フォルダは自動で検出されます。復元にスキャンは要りません。

## 症状別

### 退避したらアバターが壊れた / Console に Missing 警告が出る

**復元してください。** 上記の手順で元に戻ります。

戻したうえで、次を確認します。

1. そのアバターは[ルート](roots.md)に登録されていましたか？ 登録漏れが最も多い原因です。
2. 登録し直してからスキャンすると、同じものが候補に出なくなるはずです。
3. それでも候補に出るなら**誤検出の可能性があります。** 下記の報告先へ知らせてください。

### 未使用のはずなのに候補に出てこない

原因はだいたい 3 つです。上から順に確認してください。

| 確認する場所 | 何を見るか |
|---|---|
| スキャン結果の**「保護された単位」** | 保護されていませんか。理由が書いてあります |
| スキャン結果の**「暗黙ルートだけで使用中」** | ツールの設定アセットが生かしていませんか。その場で「起点から外す」で解決します |
| **ルート**タブの自動検出 | もう使わない古いアバターが起点に入っていませんか。チェックを外せます |

それでも出ない場合、**そのフォルダ内に使用中のアセットが 1 つでもあれば、まとまりごと残ります**（[判定粒度](scan.md)）。中身を確認してください。

### 変換ツールの生成物が片付かない

ツール本体と生成物が同じフォルダにあると、生成物まで保護されます。**[ツール出力フォルダ](scan.md)にその出力先を登録**してください。

### 変換元の衣装が消せない

変換後の衣装を**アバターに着せている**場合、変換元のマテリアルやテクスチャは本当に使用中です。これは正しい保護です。「変換したから元は消せる」とは限りません。

### スキャンできない・止められる

ルートが 1 つも設定されていません。この状態ではすべてが候補になって危険なため、意図的に止めています。[ルートの設定](roots.md)をしてください。

### アバターが自動検出されない

VRChat SDK が入っていないか、Prefab に `VRCAvatarDescriptor` が付いていません。フォルダ登録か個別ファイル指定で手動登録してください。

### スキャンが遅い

初回は依存関係の解析に時間がかかります。**[スキャン範囲](scan.md)を絞る**と、表示対象が減って扱いやすくなります（解析自体は常に全体で行うため、判定の正確さは変わりません）。

### 設定が消えた

設定は `Assets/zzz_pytr/Asset-Keshichaumon-Nator/Settings.asset` に保存されています。このファイルを消すと設定は失われます。古いバージョンから更新した直後であれば、旧フォルダから自動移行されているはずです。

### キャッシュ掃除を予約したのを取り消したい

キャッシュ掃除タブの **「予約をキャンセルする」** を押してください。Unity 終了時の警告ダイアログからも中止できます。

## それでも解決しないとき

**情報 (About)** タブを開いてください。

- **「GitHub Issues を開く」** から報告できます。
- **「環境情報をコピー」** を押すと、ツールのバージョン・Unity のバージョン・OS がクリップボードにコピーされます。コピーされる内容は事前に画面で確認できます。報告に貼り付けてください。

!!! tip "誤検出の報告は歓迎です"
    「使っているのに候補に出た」は、このツールにとって最も重要な不具合です。**再現できる条件（どんな配布物か、どう参照しているか）を添えてもらえると助かります。**

報告先: [GitHub Issues](https://github.com/Poyotoron/Asset-Keshichaumon-Nator/issues)
