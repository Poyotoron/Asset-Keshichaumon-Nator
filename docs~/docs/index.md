# はじめに

**いらないアセット消しちゃうもんネーター**は、VRChat のアバター改変用 Unity プロジェクトから、**どのアバターからも参照されていないアセット**を見つけて安全に片付ける Unity Editor 拡張です。

買ったまま着せていない衣装、試して外した髪型、差し替えて使わなくなったテクスチャ。こうしたものが積み上がって、プロジェクトフォルダが数十 GB になっていく——それを取り戻すためのツールです。

## 削除ではなく「退避」します

このツールの既定動作は**削除ではありません。**

!!! success "退避したものは、いつでも元に戻せます"
    未使用と判定されたアセットは、プロジェクトルート直下の `_UnusedAssets_日時/` フォルダへ **`.meta` ごと移動**されるだけです。ツールの「復元」を押せば元の場所に戻り、参照も復活します。Unity を再起動したあとでも戻せます。

なぜこうなっているかというと、**誤判定の代償が非対称**だからです。

| 起きうる間違い | 結果 |
|---|---|
| 使っていないのに残してしまう | ディスクが少し減らないだけ。無害 |
| 使っているのに消してしまう | 買った資産が壊れる。アバターが直せなくなる |

この差があるので、このツールは**判定に迷ったら必ず「残す」側に倒します。** 「たぶん未使用」は未使用として扱いません。そのぶん消し残しは出ますが、それは意図した設計です。

## このツールがやること・やらないこと

| やること | やらないこと |
|---|---|
| 参照されていないアセットの検出と退避 | メッシュやポリゴンの最適化 |
| 退避したものの復元・完全削除 | ビルド時の非破壊最適化 |
| 内容が同一な重複ファイルの検出 | アセットの再ダウンロード管理 |
| ビルドキャッシュ（`Library/`）の掃除 | `Packages/` 配下の整理 |

## 最初に知っておいてほしいこと

!!! warning "「起点」を取りこぼすと、使用中のアセットが候補に出ます"
    このツールは「登録したアバターから辿れるもの」を使用中とみなします。裏を返すと、**アバターの登録を忘れると、そのアバターが使っているアセット一式が丸ごと未使用候補になります。** 最初にやるべきことは[ルートの設定](roots.md)です。

!!! info "スキャンは何も壊しません"
    スキャンは常に非破壊です。ファイルが実際に動くのは、結果を見て自分でチェックを入れ、退避ボタンを押したときだけです。まずは気軽にスキャンしてみてください。
