# クイックスタート

初めて使うときの最短手順です。所要 5 分ほど。**この手順で失うものはありません**（最後の退避も、あとから元に戻せます）。

## 事前に

!!! danger "念のため、プロジェクトのバックアップを"
    このツールはファイルを移動します。復元機能はありますが、**Unity プロジェクトそのもののバックアップ**があるに越したことはありません。特に初回は、プロジェクトフォルダをコピーしてから試すことをおすすめします。

## 1. ツールを開く

メニューから `Tools > いらないアセット消しちゃうもんネーター` を選びます。

## 2. アバターを登録する（いちばん大事）

**ルート (Roots)** タブを開きます。

- 「アバターを自動検出」を押します。VRChat SDK が入っていれば、`VRCAvatarDescriptor` を持つ Prefab が一覧に出ます。
- 検出結果に**まだ使うアバターが全部載っているか**を確認します。
- 載っていないものがあれば、そのアバターの Prefab やシーンを含むフォルダを、ドロップ領域に**ドラッグ＆ドロップ**して登録します。

!!! warning "ここが唯一の危険な工程です"
    まだ使うアバターを登録し忘れると、**そのアバターが着ている衣装やテクスチャが丸ごと「未使用」として候補に並びます。** 迷ったら多めに登録してください。登録しすぎて困ることはありません（候補が減るだけです）。

詳しくは[ルートの設定](roots.md)へ。

## 3. スキャンする

**スキャン結果 (Scan Result)** タブを開き、**「スキャン実行（非破壊）」** を押します。

!!! success "この操作でファイルは動きません"
    スキャンは調べるだけです。何度でも押して構いません。

しばらく待つと、未使用候補がサイズの大きい順に並びます。

## 4. 結果を読む

各行には、パス・サイズ・種別・**判定根拠**が表示されます。パスをクリックすると Project ウィンドウでその場所が選択されるので、実物を確認できます。

**まずは「本当に要らない」と確信できるものが並んでいるかを確認してください。** 見覚えのないものや、使っている気がするものが混ざっていたら、その行にはチェックを入れないでください。

「消えるはずのものが出てこない」ときは[保護のしくみ](protection.md)を、「使っているのに出てきた」ときは手順 2 に戻ってください。

## 5. 選んで退避する

1. 退避したい行に**チェック**を入れます（既定では何も選ばれていません。必ず自分で選びます）。
2. 不安なら **「退避前に .unitypackage としてバックアップする」** をオンにします。
3. **「選択項目を退避（Move to Trash Folder）」** を押し、確認ダイアログの内容を読んで実行します。

対象はプロジェクトルート直下の `_UnusedAssets_日時/` へ移動します。

## 6. 確認する

Unity の Console に **Missing 参照の警告が出ていないか**を確認してください。アバターを Scene に置いて、見た目が壊れていないかも見ておくと安心です。

問題があれば、**スキャン結果タブ下部の「退避済みフォルダ」から「復元」**を押せば元に戻ります。
